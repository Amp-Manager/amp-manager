# Contributing to AMP Manager

Thanks for your interest! 🛠️

## Quick Start
1. Fork the repo
2. `npm install` → `npm run dev`
3. Make your change + test locally
4. Open a PR with a clear description

## Guidelines
- Keep changes focused and small
- Add tests if fixing a bug
- Update docs if changing behavior
- Use UTF-8 encoding for all files

## Full Documentation
Detailed workflows, architecture notes, and testing guides are in the [Contributing Wiki](../../wiki/11‐Contributing).
