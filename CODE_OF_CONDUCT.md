# Code of Conduct

## Our Pledge
We value technical excellence, respectful communication, and practical sustainability.

## Expected Behavior
- Be constructive, not destructive
- Focus on code, not personalities  
- Assume good faith

## Unacceptable Behavior
- Harassment, personal attacks, spam
- Bad-faith contributions or entitlement

## Enforcement
Violations may result in comment deletion or temporary bans.

*Inspired by Contributor Covenant, simplified for a technical audience.*
